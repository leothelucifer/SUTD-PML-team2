Serving contract: each hour the hospital sends a stay's full history so far. The service rebuilds the features exactly as in training and the model stays stateless. The only state is the alert ledger in DynamoDB: the hours already alerted, so the 6-hour cooldown holds across requests.

Latency, one client, 24 h stay, 2 CPUs: p50 41 ms · p95 67 ms · p99 116 ms (13 Nov, synthetic model, docs/serving.md) · leakage and parity tests run in CI (GitHub Actions)

17

Why the full history: a lab measured 30 hours ago is still the last lactate, and the features depend on the whole stay, so a short window alone would give different features from training. Latency is from the local Docker run; Lambda cold-start and real-data numbers are still to measure. Demo point: one command reproduces the model, the container and the monitoring report.
