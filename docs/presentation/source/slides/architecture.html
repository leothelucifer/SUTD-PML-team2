Serving contract: each hour the hospital sends the last 7 hourly rows for a stay. The service keeps that stay's carry-forward state in DynamoDB: last value and hour seen per variable, HMM state and last alert hour. Features match training exactly, and the model itself stays stateless.

Why 7 rows plus state, not "the last 24 hours": a lab measured 30 hours ago is still the last lactate, and the HMM state depends on the whole stay. Sending a window alone would give different features from training. Demo point: one command reproduces the model, the container and the monitoring report.
