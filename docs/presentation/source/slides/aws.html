Read the top row left to right: the hospital's integration engine sends the last 7 hourly rows over the VPN to a private API Gateway, which checks the OAuth2 token and forwards to the scoring service on Fargate. The service reads and writes each stay's carry-forward state in DynamoDB. The same Docker image from ECR runs SageMaker training and the API. Monitoring alarms email the owner; retraining needs team approval. Before any real use, check data-residency and health-data rules in the hospital's country.
